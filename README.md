# web-test — 형태 없는 결

디자인 확인용 정적 페이지. 브라우저로 `index.html`을 열면 됩니다.

## 규칙

1. **바탕은 무채색** — 다크는 짙은 회색, 라이트는 푸른 기운이 도는 흰색입니다. 하늘색과 황동색은 값이 바뀌는
   지점, 지금 조작 중인 요소, 읽어야 할 숫자에만 옅게 들어갑니다.
2. **테두리 없음, 대신 단차** — border와 outline은 어디에도 쓰지 않습니다.
   단차는 만질 수 있는 것(손잡이·스위치·분할 선택)과 표의 머리글에만 씁니다.
   그래프는 자기 영역을 따로 두르지 않고 배경 위에 그대로 놓입니다.
3. **빛은 언제나 위에서** — 모든 그림자가 같은 방향을 씁니다. 떠 있는 것은
   윗면에 1px 하이라이트, 아래에 부드러운 그늘(`--lit-text`, `--raise`)이 지고,
   파인 것은 그 반대(`--inset`)입니다. 글자도 같은 규칙을 따릅니다.
   그래프의 능선은 윗면이 빛을 받고(`ridge-lit`) 바로 아래에 그늘(`ridge-shade`)이
   집니다. 선 색은 위치에 따라 하늘색에서 황동색으로 천천히 옮겨 갑니다.
4. **색수차는 데이터에만** — SVG 필터 `#chroma` 하나로 그래프의 면과 게이지 호에만
   아주 옅게 적용합니다. 글자에는 쓰지 않습니다.
5. **두 모드** — DARK(짙은 회색)와 LIGHT(푸른 기운이 도는 밝은 흰색 #f5fcff).
   저장값이 없으면 시스템의 `prefers-color-scheme`을 따릅니다.
6. **이모지 없음**

## 포함된 요소

- 면적 그래프 — 세 단의 계단(`step-face`)으로 놓인 수치. 단의 면색은 거의 같고
  단의 끝(`step-edge`)만 조금 진해 경계가 읽힙니다. 간격은 물결처럼 어긋납니다.
  패널 안쪽에는 큰 캡션(DENSITY)
- 마디 표시 — 세로 인디케이터 대신 곡선의 몇 마디만 같은 색 계열의
  조금 더 낮은 명도로 짚습니다
- 기둥 그래프 — 윗면에 빛이 얹힌 채 판 밖으로 솟은 기둥, 최고값만 황동색
- 원호 게이지 3종 — 깊게 새긴 홈과 빛나는 값
- 조작 요소 — 슬라이더(끌 수 있음, 키보드 지원), 스위치, 분할 선택.
  누를 수 있는 것은 올라와 있고 고른 칸은 한 단 내려갑니다
- 표 — 괘선 대신 양 끝이 사라지는 한 줄의 결로 행을 가릅니다.
  행마다의 추세도 같은 잘라낸 종이 구조(면 + 단면의 빛 + 그늘)
- 항목 구분 — 각 항목 위에 같은 결 한 줄. 상자는 쓰지 않습니다
- 계단(`.stair`) — 절과 절 사이에 세 단. 그래프의 단과 같은 어법으로,
  면은 거의 같은 톤이고 각 단의 윗면(`--tier-edge`)만 조금 진합니다.
  고른 단과 어긋난 단을 번갈아 씁니다
- 좌우 여백의 계단 지형(`.decor`) — 1380px 이상에서만 나타나는 장식.
  왼쪽은 물결처럼 어긋난 4단 등고선, 오른쪽은 원형 4단, 아래쪽은 직각 3단.
  본문 열에서 38px 떨어져 있고 내용과 겹치지 않습니다
- 서체 스케일과 여백 4단계

그래프와 표의 수치는 모두 예시 데이터입니다.

## 폰트

Pretendard를 jsDelivr CDN에서 불러옵니다. 오프라인이면 시스템 폰트로 대체되며
레이아웃은 같습니다.

## 파일

- `index.html` — 마크업과 SVG
- `styles.css` — 색 토큰, 단차(raise/inset) 토큰, 레이아웃
- `app.js` — 모드 전환, 슬라이더, 스위치·분할 선택, 스크롤 등장
