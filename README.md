# web-test — 형태 없는 결

디자인 확인용 정적 페이지. 브라우저로 `index.html`을 열면 됩니다.

## 규칙

1. **박스 없음** — border, outline, box-shadow, 상자형 배경을 어떤 요소에도 쓰지 않습니다.
   표에는 괘선이, 그래프에는 축선과 눈금선이 없습니다. 면적 그래프의 좌우 끝은
   마스크로 배경에 녹여 수직 경계가 남지 않게 했습니다.
   (`styles.css`의 전역 리셋이 테두리를 강제로 막습니다)
2. **두 가지 모드** — `DARK`(검정 바탕 + 흰 글씨)와 `LIGHT`(생 화이트 #FFFFFF에서
   아주 옅은 파랑으로 기우는 바탕 + 하늘색 글씨, 황동색은 점으로만).
   저장값이 없으면 시스템의 `prefers-color-scheme`을 따릅니다.
3. **색수차** — 모든 큰 글자의 가장자리에서 하늘색과 황동색이 1px 미만으로 어긋납니다.
   `.ab` 클래스 + `data-text` 속성으로 만들며, 폭은 `--shift` 하나로 조절합니다.
4. **한 벌의 서체** — 한글과 라틴이 같은 골격(Pretendard)을 쓰고, 가는 굵기(100~200)에
   자간을 넓게 열어 두 문자가 같은 인상으로 읽히게 했습니다.
5. **이모지 없음**

글자 색은 모두 `background-image` + `background-clip: text`로 처리해 한 요소 안에서도
톤이 미끄러지고, 배경은 뷰포트에 고정된 한 겹의 그라디언트 레이어입니다.

## 포함된 예시 요소

- 면적 그래프(월별 밀도) — 선은 하늘색에서 황동색으로 넘어가고 끝점만 황동
- 기둥 그래프(구간 분포) — 아래로 갈수록 배경에 녹는 기둥, 최대값만 황동
- 원호 게이지 3종
- 표 — 괘선 없이 정렬과 간격으로만 구분, 비중은 사라지는 빛으로 표시
- 서체 스케일, 여백 4단계

그래프와 표의 수치는 모두 예시 데이터입니다.

## 폰트

Pretendard를 jsDelivr CDN에서 불러옵니다. 오프라인이면 시스템 폰트
(Apple SD Gothic Neo, Noto Sans KR 등)로 대체되며 레이아웃은 같습니다.
완전한 오프라인 재현이 필요하면 `npm i pretendard` 후 woff2를 저장소에 넣고
`@font-face`로 바꾸면 됩니다.

## 파일

- `index.html` — 마크업과 SVG 차트
- `styles.css` — 테마 토큰, 색수차, 레이아웃
- `app.js` — 모드 전환(로컬 저장), 스크롤 등장, 커서 빛
