# web-test — 형태 없는 결

디자인 확인용 정적 페이지. 브라우저로 `index.html`을 열면 됩니다.

## 규칙

1. **바탕은 무채색** — 화면의 대부분은 회색입니다. 하늘색과 황동색은 값이 바뀌는
   지점, 지금 조작 중인 요소, 읽어야 할 숫자에만 옅게 들어갑니다.
2. **테두리 없음, 대신 단차** — border와 outline은 어디에도 쓰지 않습니다.
   구분이 꼭 필요한 곳(그래프가 놓이는 면, 조작 요소, 표의 머리글)만
   한 단 올리거나(`--raise`) 한 단 내려서(`--inset`) 갈라 놓습니다.
   읽기만 하는 문장에는 아무 장치도 두지 않습니다.
3. **입체감은 빛과 그림자로** — 능선의 윗면은 빛을 받고(`ridge-lit`) 아랫면은
   그늘(`ridge-shade`)을 집니다. 기둥은 위가 밝고 아래로 어두워지는 원통이고,
   제목은 letterpress(아래 1px 하이라이트 + 부드러운 그림자)로 눌러 놓았습니다.
4. **색수차는 데이터에만** — SVG 필터 `#chroma` 하나로 그래프의 면과 게이지 호에만
   아주 옅게 적용합니다. 글자에는 쓰지 않습니다.
5. **두 모드** — DARK(짙은 회색)와 LIGHT(밝은 회색). 저장값이 없으면
   시스템의 `prefers-color-scheme`을 따릅니다.
6. **이모지 없음**

## 포함된 요소

- 면적 그래프 — 한 단 낮은 면(`.well`) 위에 놓이고, 능선은 윗면/아랫면이 나뉩니다
- 구간 손잡이 — 끌 수 있는 두 개의 손잡이가 그래프의 세로 커서와 연동되고,
  평균값이 실시간으로 갱신됩니다 (키보드 방향키도 지원)
- 기둥 그래프, 원호 게이지 3종
- 조작 요소 — 슬라이더, 스위치, 분할 선택. 누를 수 있는 것은 올라와 있고
  고른 칸은 한 단 내려갑니다
- 표 — 괘선 없이, 머리글 아래에만 한 줄의 단차. 행마다 작은 능선(추세)
- 서체 스케일과 여백 4단계

그래프와 표의 수치는 모두 예시 데이터입니다.

## 폰트

Pretendard를 jsDelivr CDN에서 불러옵니다. 오프라인이면 시스템 폰트로 대체되며
레이아웃은 같습니다.

## 파일

- `index.html` — 마크업과 SVG
- `styles.css` — 색 토큰, 단차(raise/inset) 토큰, 레이아웃
- `app.js` — 모드 전환, 구간 손잡이, 스위치·분할 선택, 스크롤 등장
