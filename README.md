# web-test — 형태 없는 결

디자인 확인용 정적 페이지. 브라우저로 `index.html`을 열면 됩니다.

## 규칙

1. **박스 없음** — border, outline, box-shadow, 상자형 배경을 어떤 요소에도 쓰지 않습니다.
   구획은 오직 간격과 밝기 차이로 만듭니다. (`styles.css`의 전역 리셋이 이를 강제)
2. **세 가지 테마** — 배경과 글씨 모두 옅은 톤 차이 또는 그라디언트를 가집니다.
   - `어둠` 검정 배경 + 흰 글씨
   - `황동` 흰 배경 + 황동색 글씨
   - `하늘` 흰 배경 + 연한 하늘색 글씨 (본문은 가독성을 위해 한 단계 깊은 톤)
3. **이모지 없음** — 텍스트와 코드 어디에도 사용하지 않습니다.

글자 색은 모두 `background-image` + `background-clip: text`로 처리해 한 요소 안에서도
톤이 미끄러지게 했고, 배경은 뷰포트에 고정된 한 겹의 그라디언트 레이어입니다.

## 파일

- `index.html` — 마크업
- `styles.css` — 테마 토큰과 레이아웃
- `app.js` — 테마 전환(로컬 저장), 스크롤 등장, 커서 빛
